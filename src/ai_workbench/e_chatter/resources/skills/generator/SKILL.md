# Generator

Gather the display name, desired writing/discussion tasks, boundaries and
authorized material before proposing a character. Do not impersonate a real
person or reconstruct source passages. Build a compact routing SKILL.md with
only useful task references; preserve evidence, uncertainty and quote limits.

Use the application task's supplied material and staged builder. Source planning
and README generation may write only to copied material in that task's staging.
Return candidate files or a builder intake to the application; it validates and
stages the proposal. User acceptance creates an application-owned version.
No Workspace installation, task ledger, host path or character-system runtime
is required. Do not change the bundled generator or shared application policy.
